# LUMEN — фронтенд виртуального казино

Сайт на «чистом» HTML/CSS/JS без сборщика и зависимостей. Бэкенд — Google Apps Script + Google Таблицы (файл `Code.gs` лежит отдельно, рядом с этой папкой). Валюта только виртуальная.

## Быстрый старт

1. Откройте `js/config.js` и вставьте адрес веб-приложения Apps Script (оканчивается на `/exec`).
2. Выложите папку целиком на любой статический хостинг с HTTPS (Netlify, Cloudflare Pages, GitHub Pages) или откройте `index.html` локально.
3. Чтобы собрать Android-приложение, используйте PWABuilder (сайт уже готов как PWA: `manifest.json`, `sw.js`, `icons/`).

## Как это работает

- **Скрипты — обычные (не модули).** Все файлы делят одну глобальную область, поэтому порядок `<script>` в `index.html` важен: файл может использовать то, что объявлено в файлах выше. Новый раздел подключайте перед `js/pwa.js`.
- **Логика игр на сервере.** Клиент только показывает результат. Случайность, баланс, шансы, права доступа считает `Code.gs`, подделать их из браузера нельзя.
- **Состояние.** После каждого действия сервер возвращает актуальные данные игрока, `applyState()` (js/core/app.js) обновляет шапку и текущий экран.
- **Экраны.** Каждый экран — `<section class="view" id="v-имя">` в `index.html`; переключение — `openView('имя')`.

## Как внести изменение

| Что нужно | Где менять |
|---|---|
| Надпись, текст кнопки, подсказка | `js/i18n/ru.js` |
| Цвета, шрифты, прозрачность стекла | `css/base.css` (переменные), `css/glass.css` |
| Фон | `css/background.css` |
| Размеры и расположение блоков | `css/layout.css`, `css/responsive.css` |
| Внешний вид конкретного раздела | `css/games.css`, `css/shop.css`, `css/social.css` |
| Поведение раздела | `js/features/<раздел>.js` |
| Адрес сервера | `js/config.js` |

### Тексты (js/i18n/ru.js)

- `T.ui` — подписи в разметке. Элемент помечен `data-i18n="раздел.ключ"`; для атрибутов: `data-i18n-placeholder`, `data-i18n-title`, `data-i18n-aria-label`.
- `T.msg` — сообщения и подписи, которые собирает JavaScript. Группа совпадает с файлом (`T.msg.games` → `js/features/games.js`), общие лежат в `T.msg.common`.
- Фразы с подстановкой чисел и имён («Выигрыш +$1.50») остаются шаблонами рядом с логикой в модуле.
- Сообщения об ошибках приходят с сервера (`Code.gs`) и переводятся там.
- Новый язык: скопируйте `ru.js` в `en.js`, переведите значения и подключите вместо `ru.js`.

### Новый раздел

1. Добавьте `<section class="view" id="v-имя">` в `index.html` (тексты — через `data-i18n`).
2. Создайте `js/features/имя.js` и подключите перед `js/pwa.js`.
3. Подпишитесь на события кнопок и вызывайте `api('действие', {...})`; для показа экрана — `openView('имя')`.
4. Если раздел должен обновляться при смене состояния, добавьте вызов в `refreshUI()` (js/core/app.js).
5. Стили положите в подходящий файл из `css/` или заведите новый и подключите в `index.html`.

## Обновление сайта

Увеличьте номер версии кеша в `sw.js` (`const CACHE = 'lumen-v2'` → `'lumen-v3'`), иначе установленное приложение может показывать старые файлы. Если добавили файл, внесите его в список `SHELL` в `sw.js`.
