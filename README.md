## 📖 О проекте (About)

**Lumen** — виртуальное казино-симулятор, созданное для демонстрации работы алгоритмов игровой логики, интерфейсных решений и взаимодействия с базами данных без какого-либо риска для пользователей.

### 🌟 Основные особенности
* 🪙 **Полностью виртуальная валюта:** Все балансы и ставки используются исключительно внутри игры.
* 🚫 **Без депозитов и вывода:** В проекте отсутствует интеграция платёжных шлюзов, эквайринга или криптовалютных кошельков.
* 🎲 **Прозрачная логика:** Алгоритмы генерации случайных чисел (RNG) реализованы для демонстрации игровых механик.
* 🛠️ **Образовательная цель:** Проект разработан для изучения веб-технологий и программирования игровой логики.
